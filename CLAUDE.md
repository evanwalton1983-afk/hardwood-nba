# House rules

Follow these in every task in this folder.

1. Additive changes only. Keep every existing feature, data field and prediction formula working unless the task says otherwise.
2. Keep the current architecture. This is a single-file HTML PWA (index.html), so keep it single-file, load libraries from a CDN with pinned versions, and add no build step.
3. Free plans only (Supabase free, Netlify free). Warn before anything that could push past a free limit.
4. Do not add paid services or new API keys without asking first.
5. No em dashes or en dashes anywhere: UI text, code comments, docs.
6. If code is copied from an MIT licensed repo, keep its copyright and license notice in a comment above that code.
7. Bump the version number shown in the app and add a dated line to CHANGELOG.md.
8. Before saying done, test at phone width and tell Evan exactly what to tap to check it.
